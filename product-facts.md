# Astro verification

- **Checked:** 2026-11-09
- **Current release verified:** Astro 7.4.8 (`npm view astro version`); Astro 7.4 was released on October 15, 2026.
- **Runtime requirement:** Node.js 22.22.0 or newer; odd-numbered Node.js 23 is not supported.
- **Environment used:** Node.js 24.22.0. The site was installed, type-checked and built successfully with this version.
- **Official sources:**
  - https://astro.build/blog/astro-740/
  - https://docs.astro.build/en/concepts/why-astro/
- **Project fit:** Astro generates the portfolio content as static HTML. Dragging and saved layout positions are small client-side enhancements rather than a client-rendered application.
- **Scope:** This is a standalone hardware/mechatronics portfolio. The existing software portfolio is not modified. The design approval record and draft directions remain in the local `design-demos/` folder, which is intentionally excluded from the public source repository.
